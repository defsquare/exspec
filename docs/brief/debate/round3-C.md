## Where another attacker is wrong

**A is wrong that `.spec` should be repaired rather than left.** A proposes fixing `.spec` so Malli schemas draw worlds and `ensure` clauses assert postconditions (`docs/dsl.md`, "Named states", "`ensure` phrases"). A ignores the structural reason why four benches, $52, and 33 commits to the generator and grammar proved only 9 of Conduit's 19 operations with 23 `inexpressible` clauses (`docs/branches/spike-recorded-cases.md`, opening, "Result").

Driving a target into a Malli-drawn pre-state through API traces (`docs/adr/README.md`, ADR-0057, ADR-0068) and fixing every result field (`docs/adr/README.md`, ADR-0070) fails whenever transitions depend on one-way hashes (bcrypt login), target-computed transforms (slugification turning `"!!!"` into `""`), or multi-filter pagination (`offset / limit` integer division) (`docs/branches/spike-recorded-cases.md`, Frame, Journal 2). To generate inputs and predict outputs there, `.spec`'s BNF (`README.md`, "Key files") would have to re-implement bcrypt, regex slugifiers, and SQL sorting—turning the specification into a second implementation [outside the dossier]. Nor did `.spec` preserve normative independence: ADR-0094 and ADR-0103 (`docs/adr/README.md`) already rewrote red specs to match target bugs like `invalid ownerId -> 500` (`docs/dsl.md`, "The HTTP surface"), while `.spec`'s `now` still failed to control the target's clock (`docs/dsl.md`, "`inexpressible`"). Repairing `.spec` retains six layers of custom compiler and SCI infrastructure (`README.md`, "Architecture") for strictly worse coverage per dollar.
